# Hackathon 2026, Grupo Datazo

This repository separates team work from the challenge resources.

## Repository map

- `resources/venture-one-reference/` stores an unchanged snapshot of the original Venture One repository. Its original `README.md` stays in that folder.
- `resources/additional/` stores extra challenge files, including the PDF brief.
- `grupo-datazo/` stores team work and agent instructions.

## Work rules

- Use `main` as the only branch. Do not create other branches.
- Keep `resources/venture-one-reference/` read-only. Copy only needed files into team work.
- Use the supplied public sample data. Do not scrape listing sites.
