# Challenge workflow notes

## Does the challenge require GitHub or Google Colab?

The brief lists a GitHub repository and a free Google Colab environment as tools provided for the challenge. It does not require teams to work only in either tool. It also does not specify a branch strategy or a team collaboration workflow.

The reference repository presents Colab as a ready-to-use path. Its notebook clones the repository, loads the challenge data, and guides participants through solution work and validation. The README also documents local Python commands to run and validate the solution.

The sources reviewed do not define a required final submission method. They do not say that all work must happen in Colab or directly on GitHub.

## Our team approach

- Keep team files in this repository and work on `main`. This is our team choice, not a challenge requirement.
- Use Colab when its prepared notebook is useful. Local Python execution is also supported by the reference README.
- Confirm the submission format separately if the organizers provide one later.

- `../resources/additional/10.pdf`, page 2, lists the repository and Colab environment as challenge resources.
