# Agent instructions

## Instructions

- Keep team code, notes, and tests in this folder.
- Treat `../resources/venture-one-reference/` as read-only. Copy only needed files and retain their source notes.
- Use `main` as the only branch. Do not create another branch.
- Use the supplied public test data. Do not scrape listing sites or use real investment opportunities.
- Use official public sources only to check existing listing fields. Keep the input unchanged and record evidence, source, license, and check date. Do not add new listings or points of interest during listing cleanup.
- Use the `write-clear-prose` skill for prose.
- At the end of each completed checkpoint, add one concise entry to `AGENT_WORKLOG.md`. Do not log each small change. Use a `YYYY-MM-DD HH:MM:SS` timestamp in America/Bogota time.
